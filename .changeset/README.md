# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works with multi-package repos, or single-package repos to help you version and publish your code. You can find the full documentation for it [in the changesets repository](https://github.com/changesets/changesets).

## Adding a changeset

To add a changeset, run `npx changeset` in the root of the repo. This will ask you:
1. Which packages have changed
2. What type of change (major, minor, patch)
3. A summary of the change

## Releasing

When ready to release:
1. Run `npx changeset version` to bump versions and generate changelogs
2. Run `npm run build` to build all packages
3. Run `npx changeset publish` to publish to npm

Or just push to `main` and the GitHub Actions workflow will handle it automatically.
