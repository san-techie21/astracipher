The Problem

AI agents have no identity

Today's AI agents operate with API keys and bearer tokens — shared secrets that can be stolen, leaked, or impersonated. There's no standard way to verify which agent is acting, what it's allowed to do, or who authorized it.

  • No cryptographic proof of agent identity
  • No capability boundaries or permission scoping
  • No audit trail of delegated authority
  • No compliance framework for regulated industries
  • Classical crypto vulnerable to quantum computers

The Solution

AgentPass: SSL for agents

AgentPass gives every AI agent a cryptographic identity — a W3C Decentralized Identifier (DID) with post-quantum resistant keys and verifiable credentials that define exactly what it can do.

  • DIDs: Unique, verifiable identity per agent
  • Credentials: Signed capability boundaries
  • Trust Chains: Delegated authority with depth limits
  • Compliance: Built-in regulatory reporting
  • PQC: ML-DSA-65 + ECDSA P-256 hybrid signing

How it works

Three lines of code to give your agent a cryptographic identity

import { AgentPass } from '@agentpass/core';

const ap = new AgentPass({ network: 'testnet' });

// Create a post-quantum secured agent identity
const { did, didId } = await ap.createAgent({
  name: 'my-trading-agent',
  description: 'Automated trading agent for equities',
});

console.log(didId);
// did:agentpass:testnet:a1b2c3d4e5f6...
// Issue a verifiable credential with capabilities
const credential = await ap.issueCredential({
  subjectDID: didId,
  capabilities: ['market-data:read', 'orders:execute'],
  permissions: [
    { resource: 'equity/*', actions: ['read', 'execute'] },
  ],
  trustLevel: 7,
  expiresIn: '90d',
  compliance: {
    framework: 'sebi-cscrf',
    encryptionKeyRegion: 'IN',
    mfaEnforced: true,
  },
});

// Credential is cryptographically signed with PQC keys
console.log(credential.proof.algorithm);
// "ML-DSA-65+ECDSA-P256"
// Verify an agent's credential — works offline!
const result = await ap.verifyCredential(credential);

console.log(result.valid);       // true
console.log(result.checks);
// {
//   structure: { passed: true },
//   expiration: { passed: true },
//   signature: { passed: true },
//   revocation: { passed: true },
// }

// Check specific permissions
const allowed = ap.hasPermission(credential, 'equity/RELIANCE', 'execute');
// true — wildcard equity/* matches
from agentpass import AgentPassClient

async with AgentPassClient(
    base_url="https://api.agentpass.dev",
    api_key="ap_your_key",
) as client:
    # Create agent with PQC identity
    agent = await client.create_agent(name="my-agent")
    print(agent.did_id)
    # did:agentpass:testnet:a1b2c3d4...

    # Verify any credential
    result = await client.verify_credential(cred)
    print(result.valid)  # True
